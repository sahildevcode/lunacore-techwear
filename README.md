# MAISON AURELIA — Timeless Eveningwear & Haute Couture

An editorial luxury couture and eveningwear e-commerce platform designed with high-fashion aesthetics, Indian Rupee (`₹`) pricing, GSAP 3.12.5 + ScrollTrigger motion architecture, and high-definition photography.

## 🌐 Live Website
- **Live Link**: [https://sahildevcode.github.io/lunacore-techwear/](https://sahildevcode.github.io/lunacore-techwear/)
- **GitHub Repository**: [https://github.com/sahildevcode/lunacore-techwear](https://github.com/sahildevcode/lunacore-techwear)

## ✨ Core Features
- **Occasionwear Architecture**:
  - **Hero Section ("Own The Moment")**: Split-text headline mask, clip-path image reveal, and parallax floating accents.
  - **Shop By Occasion (8 Arched Portal Cards)**: Evening Soirée, Weddings, Cocktail Parties, Black Tie, Romantic Date Night, Red Carpet, Summer Soirée, and Midnight Reception.
  - **Dual Split Banners**: Dedicated Eveningwear and Executive Workwear showcase.
  - **Styling Suggestions (8 Complete Curated Ensembles)**: Complete head-to-toe looks with matched handbags, stilettos, and jewelry.
  - **Bestsellers Showcase (8 Curated Pieces)**: With interactive wishlist heart toggle and quick bag additions.
  - **Community Reviews**: Authentic client testimonials across Mumbai, Delhi, London, and Dubai.
- **Motion Architecture**:
  - Auto-rotating announcement banner with smooth vertical slide transitions.
  - Sticky glassmorphic blur navbar on scroll.
  - Staggered batch entrances using GSAP ScrollTrigger.
  - Cart counter badge with scale bump animation.
  - Slide-over luxury shopping bag drawer with complimentary white-glove shipping indicator.
